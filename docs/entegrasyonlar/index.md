# Entegrasyonlar

Verimor'un SMS, Bulut Santral ve ses altyapısı; CRM sistemleri, e-ticaret platformları,
yapay zeka araçları ve kurumsal yazılımlarla entegre çalışır. Tüm entegrasyonlar
OİM üzerinden aktif hale getirilir.
